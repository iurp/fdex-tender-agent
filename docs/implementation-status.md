运行程序只读取输入与真正生成的上游对象，不读取老师期望答案。基座不需要 LLM 服务即可运行；模型可用于扩展解析与 Skills 交互，但要保留客观验证。

## 已执行的验证与尚待验证

程序测试和Word视觉检查记录见 `docs/verification.md`。CI会在GitHub重跑。初始客户端侧 WorkBuddy 导入没有在学员机器验证，仓库明确记录 NOT_TESTED；学员可先用Python基座完成任务，再补实机证据。

相关代码可以独立运行，但不代表原需求全部 AC 已通过。譬如 M08-AC2 要求图片可见字段提取，目前未实现；M13 的第二模板适配也仍待贡献。

## M04-01 本分支新增

在上述初始基座之外，M04 现在支持任务声明的无标签 UTF-8 Markdown/文本条款族，沿用原工作流信封和带标签 ID。保留实际原文、文件/行号、内容修订 ID、未知信息与冲突；显式提供上一版输出时生成版本对应。M07 按新增的语义位置字段映射表格/附件；M09 检查人数上限/精确人数，并将新增约束绑定到确认摘要。陌生要求和无法唯一对应的条款转人工复核。

范围、命令与验证材料见 [M04-01 操作说明](tasks/M04-01-implementation.md)。没有增加 PDF/OCR、任意自然语言理解、补遗法律效力裁决或 WorkBuddy 实机验证。
